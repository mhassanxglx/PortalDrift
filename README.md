# PortalDrift

PortalDrift leverages distributed architecture, load-balanced microservices, and event-driven design to create a scalable, high-performance platform framework.

PortalDrift is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/PortalDrift.git`
2. `cd PortalDrift`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure PortalDrift, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
